# LifeOS

Personal performance and finance manager — an offline web app (PWA) for your phone. Data stays on the device.

**Open on phone:** https://ziad0ghannem.github.io/Lifeos/

- Android (Chrome): menu ⋮ → Install app
- iPhone (Safari): Share → Add to Home Screen

Back up regularly from **Data and Backups → Download a backup file now**.
